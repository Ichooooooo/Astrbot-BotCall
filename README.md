# Bot-Call

AstrBot 插件：在 QQ 私聊里和机器人打网页语音电话。

## 功能

- **QQ 私聊发起语音通话**：私聊发送 `/botcall`（或直接让机器人给你打电话），手机点开链接就能聊。
- **边听边说、随时插话**：机器人朗读时可以直接开口打断，接着说你想聊的新内容。
- **随口附和不会打断**：你顺口说“嗯、对、好的”时，机器人不会被打断重来，而是从刚才停下的地方继续说完。
- **逐句朗读，不用干等**：机器人想到一句就先读一句，不用等整段话全部生成完才开口。
- **挂断后自动写通话回顾**：挂电话后自动整理聊天重点，发回 QQ 聊天并写入机器人的聊天记忆。
- **管理后台控制面板与诊断页**：在 AstrBot 后台直接点选配置、一键测试语音服务、查看各环节耗时，也能看到当前是否占线并手动挂断。

## 使用前准备与已知限制

**基本条件**：

- **AstrBot 版本**：`>=4.27.2`（不含 `4.28.x`；已完整测试 `4.27.2` 与 `4.29.x`；`4.30` 及以上版本可正常加载，若后台保存方式变化会自动转为只读，按提示到 AstrBot 原生插件设置页修改即可），且使用 AstrBot 默认的本地运行模式。
- **已配好聊天和语音服务**：在 AstrBot 中添加并启用聊天模型（需支持工具调用）、语音识别（STT）和语音合成（TTS）。
- **安装 `ffmpeg`**：AstrBot 所在的运行环境里能直接运行 `ffmpeg` 并支持 MP3 音频转换（用 Docker 部署时需确保容器里面有，装在宿主机不算）。
- **手机可访问的 HTTPS 地址**：想先体验可用免费临时隧道，长期稳定使用建议配自己的域名和 HTTPS。
- **聊天入口**：支持官方 QQ 和 OneBot 私聊（目前主要在 Android 手机 QQ 内置浏览器完成完整实测）。

**想让机器人开口更快（可选优化）**：

- **支持“边生成边播”的语音合成**：目前已适配**阿里云百炼**（如 CosyVoice 系列）与 **OpenAI 兼容格式语音合成**（如 OpenAI 官方、硅基流动 CosyVoice2 及其他兼容服务），第一句话可以边生成声音边播放，明显缩短等待时间；如果所选服务或模型不支持这种实时播放方式，插件会自动改为普通整句播放，这通电话里不再反复尝试超时。
- **单独指定电话专用聊天模型**：可在控制面板为电话单独挑一个反应快、关闭“深度思考”的模型，平时文字聊天不受影响。

**需要注意的边界**：

| 项目 | 说明 |
| --- | --- |
| 同时只能一通电话 | 整个插件同一时间只支持一通电话，每人限一通，单通最长 60 分钟；接通后连续 10 分钟没人说话会自动挂断；网络闪断 2 分钟内可重连。如果有人忘挂导致占线，管理员可在后台“评测与诊断”页直接强制挂断 |
| 语音合成兼容情况 | AstrBot 里能用的语音合成服务都可以逐句正常播报。想要第一句“边生成边播”更快开口，目前已实机验证通过**阿里云百炼**（`cosyvoice-v3-flash`）与**硅基流动**（`FunAudioLLM/CosyVoice2-0.5B`，实测约 0.3 秒即可听到开头声音）；OpenAI 官方及其他兼容服务已完成本地模拟测试，实际提速幅度取决于服务商是否边生成边返回声音 |
| 语音识别兼容情况 | 已实机验证硅基流动 `Qwen/Qwen3-ASR-1.7B`；其他在 AstrBot 里可用的语音识别服务原则上也都支持 |
| 苹果手机（iPhone） | 在 iPhone QQ 内置浏览器做过少量实测，支持首句边生成边播（若浏览器暂时拦截自动播放会自动退回整句播放）；暂未做全场景完整验收，目前主要面向 Android QQ |
| 开口速度 | 主要取决于聊天模型的反应速度，建议选响应快、关闭“深度思考”的模型 |
| 通话回顾用的模型 | 挂断后整理回顾使用的是**发起通话的原 QQ 聊天模型**（不是电话专用模型）；如果该模型额度或余额用完，回顾会失败 |
| 首次打开页面 | 新手机首次打开通话页会下载约 6 MB 的本地人声检测文件，用来在手机端判断你何时开口和停顿，下完后会缓存，后续无需重复下载 |

## 快速开始

> [!TIP]
> 新手建议直接在 AstrBot 管理后台左侧打开 **Bot-Call 控制面板** 图形化勾选配置，不需要手写英文配置名。

1. 在 AstrBot 实际运行环境内确认 `ffmpeg -version` 可以正常执行（Docker 宿主机装了不等于容器里能用）。
2. 在 AstrBot 中添加并启用聊天模型、语音识别（STT）和语音合成（TTS）。
3. 获取 Bot-Call 安装包（ZIP），在 AstrBot 管理后台 → 插件管理 → 上传安装。
4. 打开后台左侧 **Bot-Call 控制面板**，选择一种接入方式：
   - **临时隧道试用**：先在 AstrBot 同一环境安装 `cloudflared`，在控制面板将接入方式选为**临时隧道**，保存并重载插件即可。
   - **固定 HTTPS（推荐长期使用）**：准备好域名和反向代理，在控制面板将接入方式选为**固定 HTTPS**并填写你的 HTTPS 网址等信息。
5. 在控制面板打开**启用通话功能**开关，保存并重载插件。
6. 在 QQ 私聊发送 `/botcall`，用手机点开链接，实际打通一轮对话即可确认可用。

<details>
<summary><strong>固定 HTTPS 最简示例（nginx 反向代理）</strong></summary>

插件配置：

```json
{
  "access_mode": "fixed_https",
  "public_origin": "https://call.example.com",
  "listen_host": "127.0.0.1",
  "listen_port": 6191,
  "trusted_proxies": ["127.0.0.1"]
}
```

nginx 配置（把证书路径换成你的真实证书，`map` 和 `server` 都放在 `http` 段内）：

```nginx
map $http_upgrade $botcall_connection {
    default upgrade;
    '' close;
}
server {
    listen 80;
    server_name call.example.com;
    return 301 https://call.example.com$request_uri;
}
server {
    listen 443 ssl;
    server_name call.example.com;
    ssl_certificate /etc/nginx/certs/fullchain.pem;
    ssl_certificate_key /etc/nginx/certs/privkey.pem;
    client_max_body_size 4m;
    location ^~ /bot-call/ {
        proxy_pass http://127.0.0.1:6191;
        proxy_http_version 1.1;
        proxy_set_header Host $http_host;
        proxy_set_header Origin $http_origin;
        proxy_set_header X-Forwarded-Proto https;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection $botcall_connection;
        proxy_buffering off;
        proxy_request_buffering off;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
    }
    location / { return 404; }
}
```

中国大陆服务器需先完成域名备案并在防火墙/安全组放行 80 和 443 端口。Docker 部署或 Caddy 等其他反代方案详见 [使用手册](docs/使用手册.md)（在仓库或解压后的插件目录中查看）。

</details>

## 常见问题

| 问题 | 排查方向 |
| --- | --- |
| 链接打不开或提示已过期 | 确认插件管理里已启用，且控制面板的“启用通话功能”开关已打开；通话链接需在 15 分钟内打开，过期重新发 `/botcall`；固定网址请核对域名解析、HTTPS 证书和 80/443 端口 |
| 提示“当前线路正在占线” | 当前同时只支持一通电话；可等另一通结束后点击页面重试，或请管理员在后台“评测与诊断”页查看并强制挂断占线通话 |
| 听不到声音 | 检查手机媒体音量和浏览器播放授权；确认语音合成服务已启用且有余额；确认 `ffmpeg` 和 MP3 转换在 AstrBot 运行环境里可用 |
| 无法自动断句或不能插话 | 在控制面板确认录音方式和朗读时插话均为“自动（auto）”；保持通话页面在前台，戴耳机可明显减少回声；修改保存并重载后再开新通话 |
| 第一句等很久才响 | 打开后台“评测与诊断”页看哪一段最慢；常见原因是聊天模型开了“深度思考”（建议换关思考的快模型），或服务器网络代理不支持实时语音流 |
| 提示语音识别未配置或不可用 | 在控制面板的“电话专用 STT”里直接选定一个已启用的语音识别服务；注意在 AstrBot 里只添加服务不等于会话已选中 |

更多详细排查见 [使用手册](docs/使用手册.md)（在仓库或解压后的插件目录中查看）。

## 隐私

你的通话声音会通过 HTTPS 加密传到你自己的 AstrBot 服务器，再交由你配置的语音识别、聊天模型和语音合成服务处理。手机端的人声检测使用随包自带的开源本地模型在浏览器里直接运行，不会把录音发给额外的人声检测服务。使用临时隧道时，通话流量会经过 Cloudflare。通话邀请链接一次性有效且仅限发起人使用，请勿转发他人。通话产生的临时合成音频和未识别原音，会在通话回顾完全发回并写完记忆后按保留天数自动清理（默认保留 7 天，填 0 可关闭自动清理），文字记录与通话回顾会继续保留；在回顾未完成前不会清理音频材料。外部服务商的数据留存和隐私条款请以各服务官网说明为准。
